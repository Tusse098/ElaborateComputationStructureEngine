# ElaborateComputationStructureEngine (ECSEngine)
This is my own effort in creating a ECS game Engine.
A game engine that utilizes ECS structure to create 2D games similar to Unity DOTS (Unity ECS), a relatively new way of building games in Unity in a data-oriented design. Compared to the traditional object-oriented Unity we all know and, sometimes, love, Unity DOTS guides the developer toward better memory management and less cache misses. By seperating the methods and member of classes into components for the data, and systems for the methods/functions, we store the type of data close to eachother and query through a single type or types of data in bulk. By also using archetypes to group multiple components into a single combined archetype we can do it even more effective. This comes at costs however, this means that whenever we give an entity a new component it will change its archetype and therefore make a structural change in the location of the memory, which is expensive. This is all fina and good, however, Unity is a 3D-first enviroment, and Unity DOTS is even more so, as it isn't yet equipped with the 2D rendering out of the box. So instead I am making my own 2D focused, and worse, ECS game engine.
